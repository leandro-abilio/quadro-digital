# Quadro Digital — Aluno

Veja o código do professor em tempo real no seu VSCode.

## Como usar

1. Clique no ícone 👁 na barra lateral esquerda do VSCode
2. Clique em **🔌 Conectar ao professor**
3. Digite o IP do professor (enviado no chat da turma)
4. Digite a senha da sessão
5. O painel abre com o código do professor em tempo real

## Funcionalidades

- Código atualizado automaticamente quando o professor salva
- Linha do cursor do professor destacada
- **Reconexão automática** — se a rede cair por um momento, reconecta sozinho sem precisar digitar nada de novo
- Controle de fonte local (A− / A+) — ajuste o tamanho sem afetar os outros
- Syntax highlighting para Python, JavaScript e TypeScript
- `Ctrl+A` para selecionar tudo, `Ctrl+C` para copiar

## Requisitos

- Extensão **Quadro Digital — Professor** instalada e sessão iniciada pelo professor
- Mesma rede local que o professor (Wi-Fi ou Ethernet da escola)
