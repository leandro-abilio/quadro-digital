# Quadro Digital — Professor

Transmita seu código ao vivo para os alunos diretamente no VSCode deles.

## Como usar

1. Clique no ícone 📺 na barra lateral esquerda do VSCode
2. Clique em **▶ Iniciar transmissão**
3. Defina uma senha para a sessão
4. Escolha o IP da sua rede (Wi-Fi ou Ethernet da escola)
5. Clique em **📋 Copiar dados para o chat** e cole no chat da turma
6. Os alunos usam esses dados para conectar com a extensão **Quadro Aluno**

## Controles do painel

| Controle | Função |
|---|---|
| 👁 **Apagão** | Oculta o código dos alunos — útil para fazer a turma pensar antes de mostrar a solução |
| 🧊 **Freeze** | Congela a tela dos alunos no código atual — você pode trocar de arquivo à vontade sem transmitir |
| ✂️ **Trecho** | Transmite só as linhas selecionadas no editor |
| 🔢 | Liga/desliga a numeração de linhas |
| ⏹ | Encerra a sessão |

## Temporizador

Defina o tempo no formato `MM:SS` (ex: `05:00` para 5 minutos) e use os botões ▶ ⏸ ↺ para controlar. Quando o tempo acaba, o display pisca em vermelho.

## Modo Freeze

O Freeze é diferente do Apagão:
- **Apagão** — os alunos veem uma tela em branco
- **Freeze** — os alunos continuam vendo o último código transmitido, mas você pode navegar entre arquivos à vontade sem atualizar a tela deles

## Atalho de teclado

`Ctrl+Shift+Q` — transmite o trecho selecionado no editor

## Requisitos

- Extensão **Quadro Digital — Aluno** instalada nas máquinas dos alunos
- Professor e alunos na mesma rede local (Wi-Fi ou Ethernet)
